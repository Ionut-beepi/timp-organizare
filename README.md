# TimeQuest – Organizarea timpului

TimeQuest este o aplicație cu un quiz care îi ajută pe elevi să învețe cum să își organizeze mai bine timpul.

## Pentru cine este și cum se joacă?
Aplicația este destinată elevilor din clasa a XI-a. Jucătorul citește întrebările, alege un răspuns dintre cele trei variante și primește puncte pentru răspunsurile corecte.

## Link către aplicație
[Deschide aplicația TimeQuest](http://ionut-beepi.github.io/timp-organizare/)

## Tehnologii folosite
- **HTML** – pentru structura paginii.
- **CSS** – pentru designul aplicației.
- **JavaScript** – pentru funcționarea quizului și calcularea punctajului.

Am folosit AI-ul pentru a mă ajuta să modific și să organizez codul, să adaug mai multe întrebări care apar pe rând și să îmbunătățesc designul aplicației. Am verificat rezultatul și am publicat aplicația pe GitHub Pages.
